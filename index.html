Cara Pasang

Klik panduan sesuai file yang kamu unduh.

  1. Buka Prism Launcher di PC kamu.
  2. Klik Add Instance di menu atas.
  3. Pilih tab Import (dari kiri).
  4. Klik Browse dan pilih file .zip tadi.
  5. Beri nama bebas, klik OK.
  6. Tunggu proses instalasi selesai.
  7. Klik dua kali untuk Play!

Pastikan di pengaturan instance, Java yang digunakan adalah Java 17 (wajib untuk Forge 1.20.1).

  1. Buka aplikasi Modrinth.
  2. Klik ikon (+) Plus / Add Instance di kiri bawah.
  3. Pilih menu From File (atau Import).
  4. Pilih file .mrpack yang kamu download.
  5. Modrinth bakal otomatis nge-build modpacknya.
  6. Kalau udah kelar, tinggal klik Play! Lebih gampang kan?
