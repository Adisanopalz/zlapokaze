Cara Pasang

Pilih tutorial sesuai launcher kamu.

  1. Buka Prism Launcher.
  2. Klik Add Instance di menu atas.
  3. Pilih tab Import (Import from zip).
  4. Klik tombol Browse dan pilih file .zip yang diunduh.
  5. Beri nama bebas (misal: ZlapoKazeno Server), klik OK.
  6. Tunggu proses download mod selesai.
  7. Klik Play/Launch!
*Pastikan setting Java kamu menggunakan Java 17 karena ini Forge 1.20.1.
  1. Buka aplikasi Modrinth.
  2. Klik ikon (+) Plus atau Add Instance.
  3. Pilih menu From File / Import.
  4. Pilih file .mrpack yang barusan kamu download.
  5. Modrinth bakal otomatis download semua modnya.
  6. Kalau udah selesai, tinggal klik Play!
